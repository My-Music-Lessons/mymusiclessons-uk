What the calculation includes.

Slots per station = whole slots that fit, allowing changeover only between learners. Places per window = slots × stations. Windows for the pupil list = pupils ÷ places, rounded up. A final changeover is not added after the last slot.

Unused minutes are a buffer, not extra lesson places. The model does not check staffing, instrument acoustics, accessibility, school policy or available teaching capacity. Confirm the actual pupil setup and supplier support before using a timetable.
